## 🔵 **FEATURE 2: Sincronização WiFi + NTP**

### O Que É?
Conectar ao WiFi e sincronizar hora com servidor NTP automaticamente a cada 30 minutos.

### Como Usar?
```
WIFI MeuWiFi MinhaSenh@    ← Conectar
SYNC                       ← Sincronizar agora
SYNCINTERVAL 30            ← Configurar intervalo
```

### Características
- Servidor: pool.ntp.org
- Intervalo padrão: 30 minutos
- Precision: ±1-2 segundos
- Compatível: **Pico W apenas**

## 🚀 **COMO COMEÇAR**

### 1️⃣ Compilar (5 minutos)
```bash
cd vscode_pico-sdk
mkdir build && cd build
cmake ..
make -j4
```

### 2️⃣ Gravar (2 minutos)
- Pressione BOOTSEL no Pico W
- Conecte USB
- Copie `pico_emb.uf2` para drive RPI-RP2

### 3️⃣ Usar (2 minutos)
```
Terminal Serial (115200 baud):

> WIFI seu_wifi sua_senha
✓ WiFi conectado!

> SYNC
✓ NTP sincronizado com sucesso!

Pronto! Sincronização automática ativa ✅
```
